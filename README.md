# Plastic Waste Classifier Using Computer Vision

## Project Description
This project is used to classify plastic waste into different categories using a computer vision application.

## Technologies Used
- Python
- Streamlit
- FastAPI
- Pillow
- Requests

## Features
- Upload plastic waste image
- Select plastic category
- Display classification result
- Classification history
- Result visualization
- Backend API integration

## Plastic Categories
- PET
- HDPE
- PVC
- LDPE
- Other Plastic

## How to Run

### Frontend
```bash
streamlit run main.py
```

### Backend
```bash
python -m uvicorn backend:app --reload
```

## Project Status
Prototype completed with Streamlit frontend and FastAPI backend.
